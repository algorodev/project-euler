# Project Euler

Personal solutions to [Project Euler](https://projecteuler.net) problems, implemented in Python and JavaScript.

## Structure

```
problems/
  001/
    README.md       # problem statement + answer (spoiler)
    solution.py
    solution.js
  002/
    ...
```

## Running a solution

```bash
python problems/001/solution.py
node problems/001/solution.js
```
